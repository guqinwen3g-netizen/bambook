## §5 阶段推进状态机

| 起点 → 终点 | 触发条件 | 门禁 | 阻塞条件 |
|------------|----------|------|----------|
| Phase N → Phase N+1 | 当前 Phase 全部 Wave 子波次收口 + 全量测试通过 + tsc 零错误 + check:tokens 通过 | 三件套（tsc / build / vitest） | 任一门禁未过 |
| Wave X → Wave Y | 当前 Wave 收口 commit 推送 main | 子波次全绿 | 隧道中断（如 Wave F 全量部署） |
| 代码完成 → 生产部署 | OPS Panel push-based 部署（Mac Mini 本地解压） | env 模板就绪 + seed 验证 | Cloudflare 隧道中断 |

**特殊状态**：
- `pending-deploy`：代码已 commit 但未推送 / 未部署（当前 Wave F 五批次处于此状态）
- `quarantined`：测试隔离不阻断 commit（6 项视觉基线）
- `frozen`：模块冻结不改（Dashboard 全景看板，IA 阶段冻结约束）
