### 顺带根因修复（跨域既有缺陷，均登记于对应设计文档）

| 缺陷 | 根因 | 修复 |
|---|---|---|
| POST /api/v2/crm/:id/credit-limit 恒 500 | `calculateUsedCredit` 用 `order: { customerRelationId }` 关联过滤——Invoice 模型无 order 关系（schema 为平铺字段），Prisma `Unknown argument` 报错 | 改平铺字段直接过滤（`9c216a1` 随交）；信用额度设置端点恢复 |
| 停用账号后旧 JWT 在 7 天 TTL 内仍持有全部 API 权限 | `extractActorFromRequest` 仅 `jwt.verify` 验签不查 UserAccount.status | `accountStatusGuard` 组合根守卫（30s TTL 缓存 + 停用/交接路径同进程即时失效 + DB 异常 fail-open）（`e39f6f5` 随交）；admin 既有 disable-account 端点同步接入缓存失效 |
