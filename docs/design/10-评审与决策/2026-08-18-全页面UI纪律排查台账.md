## 4. 误判澄清（subagent 报告但经验证为合规，不入台账）

- `text-[var(--text-primary)]` / `text-[var(--text-secondary)]` / `bg-[var(--recessed-bg)]` / `bg-[var(--hover-darken)]` / `border-[var(--border-c-subtle)]` / `text-[var(--danger-text)]`：**BDS 语义 token 内联引用，合规**（组 7/组 8 误判）。
- `rounded-full`：= `rounded-bds-pill` 合规（组 1 误判为"粗圆角"）。
- `font-light`：正是要求的全局字重（组 1/组 5 误判）。
- `bg-amber-500` / `text-amber-500` 在 Relations/Crm/Suppliers/Seasons/Risks/Marketing：**已不存在**（组 4 误判，行号为旧证据或匹配到字符串/注释）。
- `bg-black/18`（Settings:1546）/ `bg-black/70`（ImportWizard/QuotationImportWizard）/ `bg-black/80`（ImageUploader）：**已全部收敛为 var(--mask-bg)**，components 下 `bg-black/N` 精确扫描 0 处（组 6/组 8 误判）。
- `font-medium` 全仓 components 源码 0 处（组 1/组 5/组 8 多处误判）。
- ProcurementManager/InventoryManager/BomManager/ProductionBoard 等"缺 PageHeader"：**误判**，M1 守卫确认仅 2 个文件缺失。
- `size={20}` 图标 / `text-current` / `sizeClassName="h-11 w-11"`：标准刻度内，合规。

## 5. 结论与 Phase 2 优先级

1. **token 层已收敛**：hex 0 / 自造遮罩 0 / 过重字重 0 / 手写主按钮 0（17 处余量均装饰性豁免）。**"圆角/材质/配色对上了"的现状判断成立**。
2. **不统一根因坐实 = 布局层（L1-L8）缺失**：无容器尺寸族、无间距刻度、无表格密度、无空态组件，全靠每页手写 Tailwind——这与方案文档 §2 根因判断一致，直接重写无法根治。
3. **Phase 2 重建输入**：按 §3 台账逐页核对（L3 硬编码尺寸 10 处 / M3 3 处 / M1 2 处 / M4 264 处 / T1-T3 raw 语义色 / C1-C6 共享组件），先落 Phase 1 原语与守卫，再逐页组合重建。
4. **最高优先级**：共享组件族（C1-C6）与四大核心页（Products/Cockpit/Dashboard/OrderManager 是 L3 违例重灾区），先收编可全局受益。
