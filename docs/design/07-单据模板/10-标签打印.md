## §2 三类标签定义

### 2.1 箱唛（Carton Mark / Shipping Mark）

**用途**：粘贴在出货纸箱外表面，标识箱内货物信息，用于物流分拣和海关查验。

| 字段 | 来源 | 说明 |
|---|---|---|
| 客户名称 | Relation.englishName | 收货方（schema 真源字段名 englishName） |
| PO 号 | Order.poNumber | 客户采购订单号（schema 真源字段名 poNumber） |
| 箱号 | ShipmentLine.cartons（当前为箱数 Int） | ⚠️ 规划新增 `cartonNo` 字段（如 1/50, 2/50 逐箱编号） |
| 款号 | ProductAsset.sku | 产品款号（schema 真源字段名 sku） |
| 数量 | ShipmentLine.quantity | 本箱件数 |
| 毛重（G.W.） | ShipmentLine.grossWeight | kg（Decimal 12,3） |
| 净重（N.W.） | ShipmentLine.netWeight | kg（Decimal 12,3） |
| 尺寸 | ShipmentLine.volume（当前为体积 CBM） | ⚠️ 规划新增 `dimensions` 字段（长×宽×高 cm） |
| 产地 | ShipmentLine.countryOfOrigin | 原产地（ShipmentLine 级别，非 Order 级别） |
| 唛头标记 | Order.shippingMark | ⚠️ 规划新增字段（客户指定的唛头图形/文字） |

**模板规格**：
- 尺寸：100mm × 100mm（标准）或 100mm × 150mm（加长）
- 打印方向：纵向
- 字体：英文 Sans-serif，客户名/PO 号加粗
- 条码：箱号可选 Code 128 条码

### 2.2 吊牌（Hangtag）

**用途**：挂在成衣上的产品标识标签，含品牌信息和产品参数。客户自定义格式。

| 字段 | 来源 | 说明 |
|---|---|---|
| 品牌 | Relation.englishName（当前无独立 brandLine 字段） | ⚠️ 规划新增 `Relation.brandLine` 字段（客户品牌名） |
| 款号 | ProductAsset.sku | 产品款号（schema 真源字段名 sku） |
| 尺码 | OrderLine.itemNo（当前无独立 size 字段） | ⚠️ 规划新增 `OrderLine.size` 字段（S/M/L/XL 等） |
| 成分 | FabricProfile.composition（或 FabricCompositionLine） | 面料成分（如 100% WOOL） |
| 价格 | OrderLine.unitPrice | 零售价（客户指定币种） |
| 产地 | ShipmentLine.countryOfOrigin | MADE IN CHINA |
| 条码 | ProductAsset.sku（当前无 barcode 字段） | ⚠️ 规划新增 `ProductAsset.barcode` 字段（EAN-13 / UPC-A） |

**模板规格**：
- 尺寸：客户自定义（常见 50mm × 90mm 或 60mm × 100mm）
- 打印方向：纵向
- 字体：品牌名加粗大字，其余常规
- 条码：款号+尺码组合条码
- 材质要求：铜版纸或特种纸（客户指定）

**关键规则**：吊牌格式由客户指定，系统支持模板配置（DocumentTemplate 类型 `Hangtag`），不同客户可配不同模板。

### 2.3 洗标（Care Label）

**用途**：缝在成衣内侧的洗涤说明标签。客户自定义格式。

| 字段 | 来源 | 说明 |
|---|---|---|
| 成分 | FabricProfile.composition（或 FabricCompositionLine） | 面料成分百分比 |
| 洗涤说明 | CareInstruction 标准符号 | ⚠️ 规划新增 `CareInstruction` 模型/字段（ISO 3758 洗涤符号库） |
| 产地 | ShipmentLine.countryOfOrigin | MADE IN CHINA |
| 尺码 | OrderLine.itemNo（当前无独立 size 字段） | ⚠️ 规划新增 `OrderLine.size` 字段 |
| 客户指定信息 | Order.specialInstructions（当前为通用备注） | ⚠️ 规划新增 `Order.careLabelExtra` 字段（如 RN 号、Style 号） |

**模板规格**：
- 尺寸：标准 35mm × 70mm（可折叠）
- 打印方向：纵向
- 内容格式：国际标准洗涤符号（ISO 3758）+ 文字说明
- 材质要求：尼龙缎带或涤纶（耐水洗）

**关键规则**：洗涤符号使用国际标准 ISO 3758（纺织品保养标签规范），系统内置标准符号库。

## §3 技术方案

### 3.1 打印技术

| 方案 | 说明 | 适用场景 |
|---|---|---|
| **热敏打印机** | Zebra ZD420 / TSC TDP-225 等专业标签打印机 | 生产线批量打印箱唛 |
| **ZPL 指令** | Zebra Programming Language，直接发送打印指令到打印机 | 高速批量打印 |
| **PDF + 普通打印机** | 生成 PDF 文件，用普通打印机打印标签纸 | 小批量或临时打印 |

### 3.2 系统集成方案

```
用户在出运编辑器/订单详情页选择「打印标签」
    │
    ▼
LabelPrintDialog 选择标签类型（箱唛/吊牌/洗标）+ 打印范围
    │
    ├─ 箱唛：按运单装箱行逐箱生成
    ├─ 吊牌：按订单明细行逐款逐码生成
    └─ 洗标：按订单明细行逐款逐码生成
    │
    ▼
后端 labelPrintService 生成打印数据
    │
    ├─ 热敏方案：生成 ZPL 指令 → 前端调用本地打印服务
    └─ PDF 方案：生成 PDF → 前端下载/打印
```

### 3.3 Electron 桌面端打印能力

Electron 支持直接调用系统打印机 API：
- `webContents.print()` — 调用系统打印对话框
- `printer` 模块 — 列出可用打印机
- 本地打印服务 — 可选启动本地 HTTP 服务接收 ZPL 指令并转发到热敏打印机

### 3.4 模板管理

标签模板纳入 DocumentTemplate 体系（`07-单据模板/1-单据体系总览.md` §2.2）：
- 新增模板类型：`CartonMark` / `Hangtag` / `CareLabel`
- 模板编辑器复用现有 `DocumentTemplateManager`
- 变量映射复用现有 `DocumentSetData` 数据源
- 不同客户可配置不同模板（通过 `Relation.id` 关联）

## §5 四态规范

| 状态 | 表现 |
|------|------|
| 空态 | 无运单/订单数据时，「打印标签」按钮禁用 + 提示"请先选择运单" |
| 加载 | 生成 ZPL/PDF 时显示进度条 |
| 错误 | 打印机连接失败 / 数据缺失时显示错误信息 + 重试按钮 |
| 无权限 | 无 shipments:write 权限时隐藏打印入口 |

## §6 设计系统约束

- 标签预览使用 `bds-surface` 容器，按实际标签比例缩放展示
- 标签类型选择使用 `bds-btn-group`（三段按钮：箱唛/吊牌/洗标）
- 打印范围选择使用 `bds-select`（按运单/按订单/按款号）
- 打印按钮使用 `bds-btn bds-btn-primary`，配 `Printer` 图标
- 标签预览区域使用等比例缩放，不拉伸变形
