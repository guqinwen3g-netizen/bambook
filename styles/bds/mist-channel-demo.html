方案 A · 裸排无底座 推荐
搜索订单 / 客户 / SKU…
取消外层底座：搜索框、分段器、按钮各自成为独立胶囊，直接落在页面底上，靠 8px 间距分组。容器层数 3→1、圆角叠印清零——Linear / Notion 同款手法。且与既有「纯单搜索页不套 bar」纪律天然统一为一条规则：有无筛选只是行内元素增减，容器形态不再切换。
方案 B · 一体化单面（macOS / Stripe 工具栏式）
搜索订单 / 客户 / SKU…
只保留一个容器，内部元素全部去壳：无边框输入 + 发丝分隔线 + 文字型分段器（选中态 tint 底、不换容器）。单表面零嵌套、信息密度最高、最安静——适合表格密集页；代价是元素弱化后需要靠间距与对齐纪律维持秩序，分段器可发现性略降。
