### 本轮发现的致命问题：Electron 运行模式错误

`ps aux` 显示 Bambook 进程树是：
```
electron-vite preview → Electron . → renderer
```
**不是**：
```
electron-vite dev → Vite dev server (:3000) → Electron renderer
```

`preview` 模式加载的是 `out/renderer/` 静态构建物，文件修改不会热更新。`dev` 模式才通过 `http://localhost:3000` 加载 Vite 实时源码。**这解释了为什么改了那么多轮、reload 那么多次，前端永远没变化。**

最后一次操作：kill 了 preview 进程，启动了 `npm run electron:dev`，Vite dev server 已在 port 3000 运行，代码已确认 serve 最新版本。但用户可能面对的还是 preview 窗口，或 dev 窗口未正确打开。
