## Phase 12 — 中栏渲染范式重写（Task 72）

### 触发
Kevin 给了 4 张截图（WorkBuddy / Codex / Trae / OpenAI Work），指出 Bambook 中栏与主流 Agent 差距大

### 根因
不是 CSS 问题，是渲染范式问题：
- 主流 Agent 把响应渲染成**「带注解的文章」**——工具调用是行内注解，答案是段落
- Bambook 把响应渲染成**「堆叠的功能模块」**——每个 block 是独立容器（占满宽度+边框+背景）

### 7 条铁律（从 4 款 Agent 截图提取）
1. 工具调用 = 行内注解（图标+单行文字+▼可折叠），无背景无边框
2. 整条消息 = 一份流式文档
3. 身份锚点必须存在（头像+名字+badge）
4. 答案不被包裹（裸 markdown 段落）
5. 操作栏常驻底部
6. 代码/数据 = monospace 轻底色
7. 空白是唯一分隔符

### 实现
1. **新建 `AgentDocumentRenderer.tsx`** — 取代 AgentResponseRenderer 作为中栏渲染引擎
   - tool → `ToolAnnotation`（图标+单行文字+▼展开详情），不画容器
   - evidence → `EvidenceAnnotation`（同上）
   - approval → `ApprovalAnnotation`（内联横幅，pending 态有批准/拒绝按钮）
   - markdown → `StreamMarkdown`（裸 MarkdownRenderer，不包 container div）
   - 连续 process blocks → `ProcessGroup`（一行摘要 + 可展开的注解列表 + 左侧竖线）
   - rich blocks → 用 blockRegistry 独立渲染
   - 完成态答案前置逻辑同 AgentResponseRenderer

2. **重写 `AgentMessageCard.tsx`**
   - 加身份头（Bambook 图标 + 名字 + 思考中/时间 badge）
   - 底部常驻操作栏（复制/👍/👎/分享），不靠 hover
   - 删掉 hover 才出现的复制按钮

3. **保留旧文件不删**：AgentResponseRenderer.tsx 保留，不再被引用

### 验证
- tsc：AgentMessageCard + AgentDocumentRenderer 0 错误
- vite build：14.00s 通过
- mockup：`_phase12_mockup.html` 展示 streaming + 完成两种状态
